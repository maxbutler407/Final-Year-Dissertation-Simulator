Before you run the project:

- You need Unity version 6000.0.55f1
- A Meta Quest 3S with Link enabled, and USB debugging disabled

Then, to run the project, open it with the editor version -- this will take about 5 mins because I deleted the library and more folders to make the file smaller (this is the fastest way).

Ensure the Quest's link worked and click "Desktop" on its bottom toolbar.

Once done, find SCENE 1 and click the play button at the top of the screen -- don't worry about using any build profiles.

Enjoy!


- To speak: hold down the A button on the right controller*.
- To move: use the left analogue stick
- To turn: use the right analogue stick


The scripts which I've written are located in Assets >> Scripts.

* Ensure you speak loud and clear, holding down the A button while you speak. Once finished, let go and wait a few seconds and the intelligent NPC will reply.
