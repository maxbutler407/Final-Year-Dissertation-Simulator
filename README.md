# Introduction

For my final-year dissertation, I conducted a study measuring the effects of a realistic 3D simulator on immersion and learning using the Unity 6 Game Engine. The simulator covers the life of Phineas Gage, a man who miraculously survived having a tamping iron shot through his head in 19th Century America. To enhance this simulator, the Convai NPC AI Engine was implemented, allowing users to speak and converse with high fidelity NPCs. This heightens immersion and allows users to learn through conversation and observation of their surroundings.

This repository is solely used to display a README file as the file was too large, but screenshots are provided below.

# Gameplay

Scene 1. Focuses on Gage's accident, during which users can get to know him. The scene also contains two more intelligent NPCs having a conversation.
